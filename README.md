# Purpura Firefox Port

Firefox-oriented compatibility port of the supplied Purpura Chromium extension source.

The converted full source archive is available in the ChatGPT conversation as `purpura_firefox_port.zip`. This repository currently tracks the Firefox-specific manifest and port notes; it does not yet contain every image and source asset from the archive.

See `FIREFOX_PORT_NOTES.md` for the changes and testing instructions.
